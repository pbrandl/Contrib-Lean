# Security

The app holds the PINs (as scrypt hashes) and the pledges of real members. Please report a
vulnerability privately to the maintainer (GitHub user `pbrandl`) instead of opening a public issue,
with the steps to reproduce it. You will get an answer within a week.

Only the latest release is supported; the live installation is updated to it.

How logins, PINs, sessions and the throttling work is described in the
[security model](README.md#security-model); the reasoning behind it is in `CLAUDE.md`
("Sessions and login").
